# Private Exclusion List

The public source repo intentionally excludes:

- HMS source code,
- patient-service source code,
- doctor-service source code,
- local phase evidence directories,
- generated measurement logs,
- JFR/HProf/CDS artifacts,
- raw container evidence,
- local machine paths,
- private database or Docker configuration.

If a file is uncertain, do not publish it.


Personal DRAFTS, Patient implementation ledgers and lettered V2 phase ledgers
are excluded from the current public tree. Reviewed technical guides and
scoped measured-result summaries are public; raw inputs remain private.
