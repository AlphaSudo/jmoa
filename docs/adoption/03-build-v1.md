# 03 Build V1

V1 is the accepted original JMOA transform without V2 dependency reduction.

## Required proof

- Source revision equals B0.
- Profile, admission set, and safe-SAM inputs are frozen.
- Expected transformed sites are reported.
- Exactly the accepted JMOA runtime library is materialized.
- Adapter-reference validation reports zero missing references.
- V2 reducer output is absent.

Record the transform command and all input hashes. If an accepted transform is reused, state that explicitly; do not call it freshly trained.

For Spring Boot, verify the optimized dependencies are present in the actual launch shape, not merely in a staging directory.
