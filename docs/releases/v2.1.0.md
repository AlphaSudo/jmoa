# JMOA v2.1.0

JMOA 2.1 is the PetClinic direct-RAM evidence release.

The exact accepted R41F JMOA fat-JAR deployment reduced process PSS by
**15,241.5 KiB (14.88 MiB)** and target-cgroup `memory.current` by
**17,033,216 bytes (16.24 MiB)** versus the documented strict no-JMOA B0
exploded-Boot deployment.

The held-out result was favorable in 12/12 blocks, with exact paired sign-test
`p=0.00048828125` and process-PSS bootstrap 95% interval
`[-16,109.5, -15,052.5] KiB`. The campaign completed 81/81 sessions and passed
all frozen RAM, semantic, lifecycle, and product-cost gates.

Median lifecycle CPU increased 14.71% and median startup increased 1.652 s.
Median request and p95 latency changes were both 0 ms. The result is scoped to
the exact packaging-inclusive deployment comparison; it is not a universal
Spring Boot or content-only claim.
