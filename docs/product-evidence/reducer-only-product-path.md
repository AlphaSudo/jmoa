# Reducer-Only Product Path

`JMOA Metadata Reduction` is a separate mode: clean B0 plus the raw LVT/LVTT
reducer (`B0R`). It avoids V1 runtime support and adapter overhead.

It must be evaluated and claimed separately from `JMOA Full Optimization`.
`B0R` must never be labeled V2 because it does not contain the V1 semantic
transform or runtime library.

The existing public Visits result is historical protocol-scoped supporting
evidence for this mode; it is not a three-service complete-product result.
Each service requires a clean B0, the exact same B0 with metadata reduction,
balanced ordering, semantic equivalence, V2-C validation, and V2-D attribution.
